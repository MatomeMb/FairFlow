How It Works

Every product compiled by our API exists as three vectors:

  • Matter Photo — Product image with commerce data embedded in pixels
  • Matter URI — matter:// link for text, chat, and social
  • .thing File — Binary container for direct transfer and AI agents

Install Lens. When you click a matter:// link anywhere on the web, Lens shows a compact overlay with title, price, image, and a direct path to checkout.
