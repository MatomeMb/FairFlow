# Beta Feedback Template

**Sprint 5 Week 2**  
**Purpose:** Structured feedback from beta users  
**Owner:** CTO

---

## Quick Feedback (5 min)

```
1. Did the onboarding guide make sense? (Y/N, optional comment)
2. Were you able to compile your catalog? (Y/N)
3. Did the Lens extension work when you clicked a matter:// link? (Y/N)
4. One thing we should fix: ___________
5. One thing you'd want next: ___________
```

---

## Detailed Feedback (optional)

| Topic | Question |
|-------|----------|
| **API** | Was the API easy to use? Any unexpected errors? |
| **Documentation** | What was missing or confusing? |
| **Extension** | Did the overlay display correctly? Any performance issues? |
| **Workflow** | How would you integrate this into your existing process? |
| **Pricing** | (If discussed) What would you pay for this? |

---

## Bug Report Template

```
**What happened:** [describe]
**Expected:** [what you expected]
**Steps:** 1. ... 2. ... 3. ...
**Environment:** Chrome version, OS
**Screenshot/error:** [attach if available]
```

---

## How to Submit

- Email reply to beta coordinator
- GitHub issue (if repo shared)
- Dedicated feedback form (future)
