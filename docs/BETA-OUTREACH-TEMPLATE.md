# Beta Outreach Template

**Sprint 5 Week 2**  
**Purpose:** Email/message template for inviting beta merchants  
**Owner:** CEO

---

## Subject Line

`Beta invitation: .things that Matter — Object-Oriented Commerce`

---

## Body

```
Hi [Name],

We're building .things that Matter — infrastructure that turns products into portable, shareable commerce objects. Every product gets a matter:// link that works anywhere: chat, social, email.

We'd like to invite you to our beta program. You'll get:

- API access to compile your catalog into matter:// URIs
- Lens browser extension to view and interact with products
- Early input on features and roadmap

What we need from you:
- A product catalog (CSV or JSON) to compile
- 30–60 minutes to test and share feedback
- Willingness to report issues or suggestions

Next steps:
1. Reply to confirm interest
2. We'll send your API key and onboarding guide
3. Compile your catalog (or use our web upload)
4. Share matter:// links and test the Lens extension

Timeline: Beta runs through [date]. We aim for 5–10 merchants in this phase.

Questions? Reply to this email.

Best,
[Your name]
.things that Matter
```

---

## Short Version (for LinkedIn / DM)

```
Hi [Name] — we're launching a beta for .things that Matter (portable commerce via matter:// links). Would you be open to testing with your product catalog? ~30 min commitment. [Link to landing]
```

---

## Follow-Up (if no response in 5 days)

```
Hi [Name] — just following up on the beta invite. No pressure — if timing isn't right, we can reconnect later. Let me know either way.
```
